# Website instructions

This is Maha Zainab's academic website on GitHub Pages.
When I give you text to add or change:
- Find the correct section/file and edit it, keeping the existing style.
- Don't change anything I didn't ask for.
- Show me the change, then commit with a short clear message and push to main.
- Then run `npm run build` and `npm run deploy` so the change goes live (the site is served from the gh-pages branch, not main). If the build fails, don't deploy; tell me.
- Never delete pages or files without asking.
